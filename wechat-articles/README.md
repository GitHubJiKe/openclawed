## 🚀 关于这些文章

### 文章风格特点
1. **口语化表达** - 说人话，接地气
2. **犀利观点** - 不装不端，直抒胸臆
3. **短句节奏** - 多用短句，凸显口语化表达的节奏感
4. **情感色彩** - 带有强烈个人感情色彩，偏激主观
5. **字数控制** - 1200字左右，1500字以内

### 生成工具
这些文章由 **wechat-article-writer** 技能生成，这是一个专门为OpenClaw开发的微信文章写作助手。

## 🔧 如何使用

### 阅读文章
直接点击上面的链接即可阅读文章。

### 生成新文章
```bash
# 使用wechat-article-writer技能
node ~/.openclaw/skills/wechat-article-writer/scripts/generate.js \
  --topic "你的文章主题" \
  --output "新文章.md"
```

### 文章管理
1. 新文章请保存在此目录下
2. 更新README.md中的文章列表
3. 保持统一的文章格式
